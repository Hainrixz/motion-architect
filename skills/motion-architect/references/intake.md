# Intake

Haz todas estas preguntas **en un solo mensaje**. Lo que no respondan, se asume con el default y se dice en una línea.

| # | Pregunta | Default |
|---|---|---|
| 1 | ¿Qué cuenta el video? (producto, anuncio, intro de canal, dato, lanzamiento, logo) | — (obligatorio) |
| 2 | ¿Formato? horizontal 16:9 · vertical 9:16 · cuadrado 1:1 · 4:5 feed · varios | vertical 9:16 |
| 3 | ¿Duración? | 15 s (rango sano: 6–30 s) |
| 4 | ¿Tono? default · polished · cinematic · chaotic · deadpan · app-store · editorial · o libre | default |
| 5 | ¿Tienes referencias? Videos (URL o archivo), imágenes, capturas | ninguna |
| 6 | ¿Marca? Logo, colores, fuentes, o "usa la de este sitio/imagen" | brand.json actual |
| 7 | ¿Texto exacto que debe salir? (nombre, claim, CTA, URL) | lo propones tú |
| 8 | ¿Música y SFX? ¿Tienes pista? | sin audio |

## Cómo leer las respuestas
- "Para Reels/TikTok/Shorts" significa 9:16. "Para YouTube o una presentación" significa 16:9. "Para el feed" significa 4:5.
- "Como este video" quiere decir que la persona quiere **el ritmo y el lenguaje de movimiento** de la referencia, no una copia. Extrae el motion spec y aplícalo con su marca.
- Si dicen "varios formatos", diseña primero para el más restrictivo (9:16) y luego verifica los demás con stills.
